# Licensing

Outfitter is part of the EduCloud ecosystem and follows the ecosystem default:
**Apache License 2.0** for code, consistent with the sibling modules and with the
open-infrastructure posture of the project.

- **Code:** Apache-2.0. (The canonical full `LICENSE` text is added at the first
  public-tag / publish step, in a single atomic commit, alongside the final repo
  name if it changes from `outfitter`.)
- **Docs & specs:** CC BY 4.0 recommended.
- **Inbound = outbound.** Contributions are accepted under Apache-2.0 with a
  Developer Certificate of Origin (DCO) sign-off — see `DCO` and `CONTRIBUTING.md`.

Outfitter provisions and brokers compute; it stores usage and cost metadata, never
student records. Any data-handling terms inherit the EduCloud privacy-minimal
stance defined at the ecosystem level.
