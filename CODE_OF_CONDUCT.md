# Code of Conduct

Outfitter adopts the EduCloud ecosystem Code of Conduct. Until the shared
ecosystem document is linked here, this repository follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion focused on the work.
Report concerns to the EduCloud stewards (contact listed in the ecosystem
governance document).
